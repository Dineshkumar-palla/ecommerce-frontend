# EzMart - Full Stack E-Commerce Web Application

## 📌 Project Overview

EzMart is a modern full-stack e-commerce web application developed as a portfolio and learning project. The platform provides a seamless shopping experience for users and includes an admin dashboard for product management.

The project demonstrates frontend development, backend APIs, authentication workflows, database integration, cart functionality, and responsive UI design.

---

# 🎯 Goals

* Build a real-world e-commerce application
* Practice full-stack development
* Learn authentication and API integration
* Implement cart and admin management systems
* Deploy and maintain a production-ready application
* Showcase skills for recruiters and LinkedIn portfolio

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/ecommerce-frontend.git
```

---

## 2️⃣ Install Frontend Dependencies

```bash
npm install
```

---

## 3️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

---

# ▶️ Run Project

## Frontend

```bash
npm start
```

Runs on:

```bash
http://localhost:3000
```

---

## Backend

```bash
node server.js
```

Runs on:

```bash
http://localhost:5000
```
